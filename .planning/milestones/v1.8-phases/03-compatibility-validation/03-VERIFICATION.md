### Deviation from plan 03-04 (documented in 03-04-SUMMARY.md, accepted)

The plan's Gap 2 premise — "wrap navigation HTML containing `<a href>` via `cg.StrdupHTML`, mirroring node labels" — was **technically impossible**: GraphViz HTML-like labels silently drop any `<a href>` tag at render time (the executor verified this empirically with isolated StrdupHTML+Render probes). The executor used the correct GraphViz idiom instead: clickable `<TD HREF="url">` cells, which GraphViz renders as `<a xlink:href>` anchors in SVG. Test assertions were anchored on the plan's `<behavior>` intent (visible + clickable + unescaped) rather than the literal `<a href=` substring. This is a sound engineering decision forced by a hard engine constraint, documented as Auto-fix #1 in the SUMMARY, and the deviation does not reduce scope — the navigation bar IS clickable in the actual SVG output (6 anchors per C2/C3 file, verifier-confirmed).
