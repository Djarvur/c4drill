# Requirements: v1.11 Label Formatting Fixes

**Status:** Active (archived)
**Milestone:** v1.11 Label Formatting Fixes
**Last updated:** 2026-08-10

C4Drill's generated diagram labels must render with proper word wrapping and aspect-ratio sizing. Two user-observed defects in the render package: edge labels were emitted as plain newline-joined strings with no wrapping and no aspect-ratio sizing, and the label wrap procedure split long words mid-word. Both fixes are additive-safe: unit label output remains byte-identical where no punctuation break or over-budget word is involved, and existing diagrams did not regress (goldens enforced via canonicalDOT, DI-1).

Source: captured todos (2026-08-10), `.planning/todos/pending/` (both auto-closed by Phase 34).

## v1.11 Requirements

### LABEL — Label rendering

- [x] **LABEL-01**: Edge labels render as wrapped rectangles with aspect-ratio sizing — an edge's label (`[Technology]` + Description) is formatted like a unit label: an HTML label with invisible borders (`border="0"`), text wrapped to fit the configured aspect ratio (`LabelRatio`), instead of the current plain `\n`-joined string.
  **Outcome:** Validated — Phase 34 (plans 34-02, 34-04). Edge labels are HTML-table rectangles; width from `labelMaxCharsForText` (closed-form quadratic); measured ratio ≈1.84:1 (target 1.6); tech-only/desc-only edges render the rectangle too.
- [x] **LABEL-02**: Lines break at word boundaries only — the wrapping procedure never splits a word mid-word; words longer than the per-line character budget overflow the budget on their own line (the document author may reword instead of the tool force-splitting).
  **Outcome:** Validated — Phase 34 (plans 34-01, 34-03). Refined by UAT: break opportunities include punctuation/symbols (`->`, `:`, `-`, `_`); pure letter/digit runs still never split.

### COMPAT — Backward compatibility

- [x] **COMPAT-01**: Existing diagrams render without regression — unit labels are unchanged, and golden comparisons (canonicalDOT, DI-1) still pass.
  **Outcome:** Validated — Phase 34. `multilevel.expanded.dot` re-baselined ONLY for documented deltas (punctuation breaks, ratio re-wraps); 12/12 packages green; examples regenerated.

## Out of Scope

| Feature | Reason |
|---------|--------|
| Edge label style/styling options (colors, fonts, line styles) | Not requested; edge styling already handled by link attributes |
| Manual label positioning | GraphViz auto-layout is a core design decision (see PROJECT.md) |
| Hard-wrapping *into* the aspect ratio (scaling text to force-fit) | Violates LABEL-02 — the author chooses wording, not the tool |
