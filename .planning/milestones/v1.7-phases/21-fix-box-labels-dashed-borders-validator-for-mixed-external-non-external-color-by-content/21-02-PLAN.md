<objective>
Add validation to prevent mixing external and non-external units in C1 boxes, and color C1 boxes based on their contents (grey for externals, dark blue for non-externals).

Purpose: C1 boxes should be semantically consistent - either all external units or all internal units. This prevents confusing diagrams where a single box contains both external systems and internal components. The box color should reflect its contents: grey boxes contain external units, dark blue boxes contain internal units.

Output: Validation rule and box color determination logic.
</objective>
