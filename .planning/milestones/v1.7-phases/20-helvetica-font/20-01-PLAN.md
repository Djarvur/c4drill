# Plan: Add Helvetica Font to All Elements

**Phase:** 20 - Helvetica Font
**Plan:** 20-01
**Depends on:** Phase 19 (Queue Label Fix)

## Goal

Add `fontname="Helvetica"` to cluster (subgraph) labels and edge labels for consistent typography across all diagram elements.

---

## Context

The graph root already sets Helvetica font via `cg.SetFontName("Helvetica")` in `converter.go:167`. However, this doesn't automatically apply to:
1. Cluster (subgraph) labels - need explicit `fontname` attribute
2. Edge labels - need explicit `fontname` attribute

---

## Tasks

### Task 1: Add fontname to cluster labels

**File:** `internal/render/converter.go`

**Location:** `createCluster` function (around line 380)

**Action:** Add `fontname="Helvetica"` attribute to subgraph when cluster has a label.

```go
// After setting fontcolor (line 382)
if err := setClusterAttribute(subgraph, "fontname", "Helvetica"); err != nil {
    return nil, err
}
```

---

### Task 2: Add fontname to edge labels

**File:** `internal/render/converter.go`

**Location:** `createEdge` function (around line 430)

**Action:** Set `SetFontName("Helvetica")` on the edge when it has a label.

```go
// After setting font size (line 431)
if e.label != "" {
    e.SetFontName("Helvetica")
}
```
