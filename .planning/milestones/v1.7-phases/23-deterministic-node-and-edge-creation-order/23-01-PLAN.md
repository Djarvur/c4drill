## Standard Go pattern for sorted map iteration

```go
import (
    "maps"
    "slices"
)

// For map[string]*T:
keys := slices.Collect(maps.Keys(m))
slices.Sort(keys)
for _, k := range keys {
    v := m[k]
    // process
}
```
