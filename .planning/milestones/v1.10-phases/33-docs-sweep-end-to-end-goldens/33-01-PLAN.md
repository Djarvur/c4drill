  <files>internal/testutil/canonical/canonical.go, internal/testutil/canonical/canonical_test.go, internal/graph/builder_test.go</files>
  <behavior>
    `canonical.Canonical(t, dot)` normalizes a DOT document into an order-insensitive semantic serialization (STATE.md DI-1). It:
    1. Parses the DOT (skipping the `digraph ... {` header, recursing into subgraphs, parsing attribute/node/edge statements with quoted-string and HTML-label awareness so `];`, `{`, `}` inside values do not truncate parsing).
    2. Strips layout geometry attributes (`bb`, `pos`, `lp`, `lheight`, `lwidth`, `height`, `width`) — these are go-graphviz engine output that flips between runs and carries no semantic content.
    3. Sorts the remaining attributes within each statement, and sorts statements recursively (siblings ordered by their canonical form; multiset semantics preserved via dedup-unsafe sort+join).

    The function is pure (no I/O, no global state), deterministic, and depends only on stdlib `sort` + `strings`. It uses `testing.T` only for `t.Helper()` marking (no assertions inside — callers assert).

    The 3 WR-01/WR-2 regression tests move with it and MUST still pass unchanged (they are the contract that the extraction was behavior-preserving).
  </behavior>
