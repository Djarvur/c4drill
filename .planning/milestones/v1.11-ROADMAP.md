# Milestone v1.11: Label Formatting Fixes

**Status:** ✅ SHIPPED 2026-08-10
**Phases:** 34
**Total Plans:** 4

## Overview

Fix user-observed label-formatting defects in generated diagrams: edge labels now render as borderless HTML-table rectangles with aspect-ratio sizing (like unit labels), line breaking happens at word boundaries AND punctuation boundaries, and label rectangles self-consistently approximate the configured `LabelRatio`. Found via UAT on the generated `mise-architecture.toml` diagrams; three UAT gaps were diagnosed and fixed with two gap-closure plans.

## Phases

### Phase 34: Label formatting fixes

**Goal**: Users see properly formatted labels: edge labels render as wrapped rectangles with invisible borders and aspect-ratio sizing (the same HTML table form unit labels use), and no label text is ever split mid-word.
**Depends on**: Phase 33
**Plans**: 4 plans

Plans:

- [x] 34-01: Word-boundary-only wrapping (`splitLongWord` char-level fallback removed; over-budget words emit unsplit on their own line — D-05)
- [x] 34-02: Edge labels as borderless `<table border="0">` rectangles (`[Tech]` row + wrapped Description; `SetLabelHTML`; empty-label golden parity preserved)
- [x] 34-03: Punctuation-aware tokenizer (UAT fix — `->`, `:`, `-`, `_` are break opportunities; symbols like `>` included via "not wordChar and not space"; no-space rejoin)
- [x] 34-04: Self-consistent aspect-ratio sizing (UAT fix — closed-form quadratic `labelMaxCharsForText`, edge + unit labels; measured edge label ratio ≈ 1.84 vs 0.2 before)

**Details:**
- **LABEL-01 implementation surface:** `buildEdgeLabel` (internal/render/labels.go) rewritten to the HTML-table rectangle; `createEdge` uses `SetLabelHTML` (converter.go), empty labels keep `SetLabel("")` for COMPAT-01 golden parity (REF-05).
- **LABEL-02 implementation surface:** `wrapText` (internal/render/wrap.go) tokenizes via `tokenizeWrapText` — whitespace + punctuation/symbol boundaries, trailing attachment (`Multi-`, `YUV420->`), leading attachment (`[CGF`); `spaceBefore` only from whitespace so punctuation rejoin inserts no space.
- **Ratio sizing:** `labelMaxCharsForText(fixedRows, textLen, ratio)` — closed-form positive root of width² − B·width − C = 0 (B = fixedRows·pointsPerRow·ratio, C = textLen·pointsPerChar·pointsPerRow·ratio); deliberately not iterative (ceil oscillation). Wired into edge, no-icon, cylinder (×2.2), queue (×1.6), person (icon column) builders with `minCharsPerLine` floor.
- **Golden impact:** `multilevel.expanded.dot` re-baselined twice — for punctuation-break semantics (34-03: `(open/close)` → `(open/<BR/>close)`, `lock-state` hyphen break) and ratio sizing (34-04: unit label line-budget re-wraps). All deltas label-only; geometry stripped by canonicalDOT (DI-1).
- **Examples:** `examples/{overflow-test,cloud-system,rank-for-better-layout}` SVGs regenerated; overflow-test shows the punctuation-wrapped, ratio-sized edge label.
