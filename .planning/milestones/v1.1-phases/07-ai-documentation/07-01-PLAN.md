   - `[properties]` section with all 8 fields

   - All unit fields (13 total)
   - Link syntax (`link` and `linkFrom`) with all 7 link attributes

   - Referenced units must exist

   - "Generate TOML for: [architecture description]"
   - Include 3-5 prompt templates
6. **Examples Section:** Reference the 5 example files with brief descriptions

**Style guidelines:**
- Concise, reference-style (not tutorial)
- Use tables for type/field references
- Code blocks for all TOML examples
- AI-focused: "When generating TOML..." phrasing
