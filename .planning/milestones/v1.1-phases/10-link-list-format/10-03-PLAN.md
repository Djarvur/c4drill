Current iteration pattern (MAP):
```go
for target := range unit.Links {
    // target is the key (string)
    // link.Target contains the same value
}

for source, link := range unit.LinksFrom {
    // source is the key, link.Target was set to source
}
```

NEW iteration pattern (SLICE):
```go
for _, link := range unit.Links {
    // link.Peer contains the target name
    target := link.Peer
}

for _, link := range unit.LinksFrom {
    // link.Peer contains the source name
    source := link.Peer
}
```
