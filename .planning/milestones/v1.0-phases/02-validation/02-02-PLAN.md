<action>
Create the individual validation rule functions.

1. Create internal/validator/rules.go with three rule functions:

   validateReferences(m *parser.Model, index map[string]*UnitInfo) ValidationErrors
   - Check all Links[target] references exist in index
   - Check all LinksFrom[source] references exist in index
   - Include suggestion using formatSuggestion for undefined references
   - Use concise message: `undefined unit "X" referenced from "Y"`

   validateSubunitRules(m *parser.Model, index map[string]*UnitInfo) ValidationErrors
   - Only TypeSystem, TypeSystemExternal, TypeBox can have subunits
   - All other types with subunits produce error
   - Use concise message: `unit "X" has type Y which cannot have subunits`

   validateLinkRules(m *parser.Model, index map[string]*UnitInfo) ValidationErrors
   - Units with subunits cannot have Links (VALD-02)
   - Units with subunits cannot have LinksFrom (VALD-02)
   - Links cannot target units with subunits (VALD-03)
   - Use concise message: `unit "X" has subunits and cannot have direct links`
   - Use concise message: `unit "X" has subunits and cannot be linked to directly`

2. Create internal/validator/rules_test.go with comprehensive tests:
   - Test each rule independently
   - Test edge cases (empty model, single unit, deeply nested)
   - Test both positive (valid) and negative (invalid) cases
   - Verify error message format
