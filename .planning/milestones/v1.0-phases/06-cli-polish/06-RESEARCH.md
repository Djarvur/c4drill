## Summary

Phase 6 implements the final polished CLI using the Cobra framework to integrate all prior phases (parser, validator, view generator, graph builder, renderer, output writer). The CLI follows Unix conventions: silent on success, errors to stderr, proper exit codes. Cobra provides auto-generated help text with usage examples.

**Primary recommendation:** Use Cobra's `RunE` pattern for error propagation, `SilenceUsage: true` to suppress usage on runtime errors, and `cmd.OutOrStderr()` for error output. Wire the full pipeline in a single root command with persistent flags for format and output directory.

### Pattern 1: Cobra RunE Pattern for Error Propagation

**What:** Use `RunE` instead of `Run` to return errors up the call stack. Cobra handles error printing to stderr automatically.

**When to use:** Always for CLIs that need proper exit code handling.

**Example:**
```go
// Source: Cobra best practices (training knowledge, HIGH confidence)
var rootCmd = &cobra.Command{
    Use:   "c4drill <input.toml>",
    Short: "Generate C4 architecture diagrams from TOML",
    Long: `Generate C4 architecture diagrams from TOML definitions.

Supports C1 (Context), C2 (Container), and C3 (Component) level diagrams
with drill-down navigation between levels.

Examples:
  c4drill architecture.toml
  c4drill architecture.toml -o ./docs/diagrams
  c4drill architecture.toml -f dot -o ./output`,
    Args: cobra.ExactArgs(1),
    RunE: runRoot,
    SilenceUsage: true,  // Don't print usage on runtime errors
}

func runRoot(cmd *cobra.Command, args []string) error {
    inputPath := args[0]

    // Stage 1: Parse
    model, err := parser.ParseFile(inputPath)
    if err != nil {
        return fmt.Errorf("parse: %w", err)
    }

    // Stage 2: Validate
    errors := validator.Validate(model)
    if len(errors) > 0 {
        // Report to stderr
        validator.ReportErrors(errors, cmd.OutOrStderr())
        return fmt.Errorf("validation failed")
    }

    // Stage 3-6: Generate, build, render, write
    // ... (full pipeline)

    return nil // Success - silent
}
```

### Pattern 2: Flag Definition with Defaults

**What:** Define persistent flags with both short and long forms, sensible defaults, and validation.

**Example:**
```go
// Source: Cobra documentation patterns (training knowledge, HIGH confidence)
var (
    format    string
    outputDir string
)

func init() {
    rootCmd.PersistentFlags().StringVarP(&format, "format", "f", "svg",
        "Output format (dot|svg)")
    rootCmd.PersistentFlags().StringVarP(&outputDir, "output", "o", ".",
        "Output directory")

    // Mark format for validation
    rootCmd.RegisterFlagCompletionFunc("format", func(cmd *cobra.Command, args []string, toComplete string) ([]string, cobra.ShellCompDirective) {
        return []string{"dot", "svg"}, cobra.ShellCompDirectiveNoFileComp
    })
}

// Validation in PreRunE or RunE
func validateFlags() error {
    if format != "dot" && format != "svg" {
        return fmt.Errorf("invalid format %q: must be dot or svg", format)
    }
    return nil
}
```

### Pattern 4: Full Pipeline Orchestration

**What:** The RunE function orchestrates all phases in sequence, propagating errors.

**Example:**
```go
func runRoot(cmd *cobra.Command, args []string) error {
    inputPath := args[0]

    // Validate flags
    if err := validateFlags(); err != nil {
        return err
    }

    // Parse
    model, err := parser.ParseFile(inputPath)
    if err != nil {
        return fmt.Errorf("parse: %w", err)
    }

    // Validate
    if errors := validator.Validate(model); len(errors) > 0 {
        validator.ReportErrors(errors, cmd.OutOrStderr())
        return fmt.Errorf("validation failed with %d errors", len(errors))
    }

    // Get basename from input file
    basename := strings.TrimSuffix(filepath.Base(inputPath), filepath.Ext(inputPath))

    // Create output writer
    writer := output.NewWriter(outputDir)

    // Generate and write C1 view
    if err := generateAndWrite(model, "", basename, format, writer); err != nil {
        return err
    }

    // Generate and write C2/C3 views for expanded units
    expandedUnits := collectExpandedUnits(model)
    for _, unitPath := range expandedUnits {
        if err := generateAndWrite(model, unitPath, basename, format, writer); err != nil {
            return err
        }
    }

    return nil // Success - silent on success per spec
}
```

### Anti-Patterns to Avoid

- **os.Exit() in RunE:** Calling os.Exit() prevents proper error propagation and cleanup. Return error instead.
- **fmt.Print in RunE for errors:** Cobra handles error printing. Return error to use its built-in stderr handling.
- **SilenceUsage: false with validation errors:** Causes verbose output. Set SilenceUsage: true for cleaner error messages.
- **Global variables for flag values outside init():** Define flags in init() to ensure they're parsed before RunE executes.

## Don't Hand-Roll

| Problem | Don't Build | Use Instead | Why |
|---------|-------------|-------------|-----|
| Flag parsing | Manual os.Args parsing | cobra.Flags() | Handles short/long forms, defaults, validation, help generation |
| Help text generation | Manual strings | cobra.Long/Short | Auto-formatted with proper indentation and flags |
| Exit code handling | Multiple os.Exit calls | Single check after Execute() | Cleaner control flow, testable |
| Version printing | Custom --version handler | cobra.SetVersionTemplate() | Built-in support with ldflags injection |

**Key insight:** Cobra's conventions handle 90% of CLI boilerplate. Only the pipeline logic is custom.

## Common Pitfalls

### Pitfall 1: Forgetting SilenceUsage
**What goes wrong:** Every error prints full usage text, making errors hard to read.
**Why it happens:** Cobra defaults to showing usage on any error.
**How to avoid:** Set `SilenceUsage: true` on commands where errors are data/validation issues, not usage mistakes.
**Warning signs:** Users see usage text after "file not found" errors.

### Pitfall 2: Mixing stdout and stderr
**What goes wrong:** Errors go to stdout, breaking pipe semantics.
**Why it happens:** Using fmt.Println instead of cmd.OutOrStderr().
**How to avoid:** Always use `cmd.OutOrStderr()` for error output, `cmd.OutOrStdout()` for success output (if any).
**Warning signs:** `c4drill missing.toml 2>/dev/null` still prints errors.

### Pitfall 3: Not propagating errors with context
**What goes wrong:** "exit status 1" with no indication what failed.
**Why it happens:** Returning errors without wrapping.
**How to avoid:** Use `fmt.Errorf("stage: %w", err)` to add context at each pipeline stage.
**Warning signs:** User reports "it failed" without actionable information.

### Pitfall 4: Validating flags after expensive operations
**What goes wrong:** CLI parses entire file before reporting invalid --format.
**Why it happens:** Flag validation in RunE instead of PreRunE.
**How to avoid:** Validate flags in PreRunE or early in RunE before file I/O.
**Warning signs:** Long delay before "invalid format" error.

### Pitfall 5: Forgetting to handle basename edge cases
**What goes wrong:** Input path "/tmp/.toml" produces empty basename.
**Why it happens:** Using filepath.Base without validation.
**How to avoid:** Validate basename is non-empty, derive from parent directory if needed.
**Warning signs:** Output files named ".svg" or in wrong locations.

    "github.com/Djarvur/c4drill/internal/view"
    "github.com/spf13/cobra"
)

var (
    format    string
    outputDir string
    version   = "dev" // Set via ldflags
)

func NewRootCmd() *cobra.Command {
    cmd := &cobra.Command{
        Use:   "c4drill <input.toml>",
        Short: "Generate C4 architecture diagrams from TOML",
        Long: `Generate C4 architecture diagrams from TOML definitions.

Supports C1 (Context), C2 (Container), and C3 (Component) level diagrams
with drill-down navigation between levels.

Examples:
  c4drill architecture.toml
  c4drill architecture.toml -o ./docs/diagrams
  c4drill architecture.toml -f dot -o ./output

Output:
  - C1 diagram: {basename}.{format}
  - C2 diagrams: {basename}/{system}.{format}
  - C3 diagrams: {basename}/{system}/{container}.{format}`,
        Version: version,
        Args:    cobra.ExactArgs(1),
        RunE:    runRoot,
        SilenceUsage: true,
    }

    cmd.PersistentFlags().StringVarP(&format, "format", "f", "svg",
        "Output format (dot|svg)")
    cmd.PersistentFlags().StringVarP(&outputDir, "output", "o", ".",
        "Output directory")

    return cmd
}

func runRoot(cmd *cobra.Command, args []string) error {
    // Validate flags early
    if format != "dot" && format != "svg" {
        return fmt.Errorf("invalid format %q: must be dot or svg", format)
    }

    inputPath := args[0]

    // Stage 1: Parse
    model, err := parser.ParseFile(inputPath)
    if err != nil {
        return fmt.Errorf("parse: %w", err)
    }

    // Stage 2: Validate
    if errors := validator.Validate(model); len(errors) > 0 {
        validator.ReportErrors(errors, cmd.OutOrStderr())
        return fmt.Errorf("validation failed")
    }

    // Derive basename from input file
    basename := strings.TrimSuffix(filepath.Base(inputPath), filepath.Ext(inputPath))
    if basename == "" {
        basename = "diagram"
    }

    // Create output writer
    writer := output.NewWriter(outputDir)

    // Stage 3-6: Generate all views and write
    if err := processAllViews(model, basename, writer); err != nil {
        return err
    }

    return nil // Success - silent per spec
}

func processAllViews(model *parser.Model, basename string, writer *output.Writer) error {
    // Collect all expanded unit paths
    expandedPaths := collectExpandedPaths(model)

    // Process each view
    for _, unitPath := range expandedPaths {
        if err := processView(model, unitPath, basename, writer); err != nil {
            return err
        }
    }

    return nil
}

func processView(model *parser.Model, unitPath, basename string, writer *output.Writer) error {
    // Generate appropriate view based on path
    var v *view.View
    if unitPath == "" {
        v = view.GenerateC1View(model)
    } else if isC2Path(model, unitPath) {
        v = view.GenerateC2View(model, unitPath)
    } else {
        v = view.GenerateC3View(model, unitPath)
    }

    if v == nil {
        return fmt.Errorf("failed to generate view for %q", unitPath)
    }

    // Build graph with navigation
    g := graph.BuildGraphWithPath(v, unitPath, basename, format)
    if g == nil {
        return fmt.Errorf("failed to build graph for %q", unitPath)
    }

    // Render
    data, err := render.Render(g, format)
    if err != nil {
        return fmt.Errorf("render: %w", err)
    }

    // Write
    if err := writer.Write(basename, unitPath, format, data); err != nil {
        return fmt.Errorf("write: %w", err)
    }

    return nil
}
