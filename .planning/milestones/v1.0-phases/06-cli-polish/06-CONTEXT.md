<decisions>
## Implementation Decisions

### CLI Framework
- Use Cobra framework (industry standard for Go CLIs)
- Auto-generates help text and usage
- Supports short and long flag forms
- Adds version command capability

### Flags
- `--format` / `-f`: Output format (dot|svg), default: **svg**
- `--output` / `-o`: Output directory, default: **.** (current directory)
- Single positional argument: input TOML file

### Success Output
- Silent on success (print nothing, exit 0)
- Unix philosophy: no noise, scripts check exit code

### Error Handling
- All errors written to stderr
- Exit code 1 on any error
- Error format: `error: {message}` (consistent with parser/validator)

### Help Text
- Auto-generated by Cobra
- Include usage examples in Long description
- Show available formats and defaults

### Exit Codes
- 0: Success
- 1: Error (parse, validation, render, file I/O)

</decisions>
