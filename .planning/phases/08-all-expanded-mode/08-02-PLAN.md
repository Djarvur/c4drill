Add BuildExpandedGraph function and buildNestedCluster helper for recursive cluster construction.

Implementation:

1. Add new function `BuildExpandedGraph(v *view.View) *Graph`:
   - Create Graph with same structure as BuildGraph
   - For each top-level unit in v.Units:
     - If unit has subunits: call buildNestedCluster, append to g.Clusters
     - Else: call buildNode, append to g.Nodes
   - Build edges using existing buildEdges(v)
   - No navigation (all-expanded has no drill-down)

2. Add helper `buildNestedCluster(entry *view.Entry, path string) *Cluster`:
   - Create cluster with ID "cluster_" + path (use dotted path for uniqueness)
   - Set Label from entry (name, technology, description, icon)
   - Set Style using GetStyleForType
   - For each subunit:
     - Build childPath = path + "." + childName
     - If childUnit has subunits: recursively call buildNestedCluster, append to cluster.Clusters
     - Else: buildNode for child, append to cluster.Nodes
   - Return cluster

3. Key points:
   - Use full dotted path in cluster ID to avoid naming conflicts (e.g., "cluster_mainapp.api" not "cluster_api")
   - Recursion depth is unlimited (per locked decision: no size limits)
   - All edges including cross-level are handled by existing buildEdges() - it processes all units in view.Units

Reference existing buildCluster (lines 68-93) for the pattern, but add recursive cluster handling.

```go
func processExpandedView(m *parser.Model, basename string, writer *output.Writer) error {
    v := view.GenerateExpandedView(m)
    if v == nil {
        return fmt.Errorf("%w: expanded view", errGenerateView)
    }
    
    g := graph.BuildExpandedGraph(v)
    if g == nil {
        return fmt.Errorf("%w: expanded graph", errBuildGraph)
    }
    
    data, err := render.Render(g, format)
    if err != nil {
        return fmt.Errorf("render: %w", err)
    }
    
    if err := writer.WriteExpanded(basename, format, data); err != nil {
        return fmt.Errorf("write: %w", err)
    }
    
    return nil
}
```

Key points:
- Early return ensures C1/C2/C3 code path is completely skipped (EXPD-05)
- No navigation URLs in expanded view (single diagram, no drill-down)
- Uses same format flag and render pipeline
- Output goes to WriteExpanded for {basename}.expanded.{ext} naming
