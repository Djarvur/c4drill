## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fmt args -> in-place file rewrites | formatter output REPLACES author files — corruption or injection here is destructive |
| recursive dir walk -> file selection | author-controlled paths; walk must stay bounded and skip symlinks |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-35-08-01 | Tampering | in-place rewrite | mitigate | Semantic safety gate: candidate output must re-parse to a Model require.Equal to the original BEFORE any file is replaced; malformed outputs are hard errors and the file is left untouched. |
| T-35-08-02 | Tampering | recursive walk | mitigate | filepath.WalkDir (no symlinked-dir following), extension filter *.c4d/*.toml only — fmt cannot be pointed at arbitrary file types. |
| T-35-08-03 | DoS | huge/pathological files | accept | Local developer tool over own files; parse costs bounded by MaxExpressions (C4D) and go-toml (TOML). |
| T-35-08-04 | Repudiation | --check CI gate | mitigate | Exit 1 + explicit file list output makes CI failures attributable to specific files. |
</threat_model>
