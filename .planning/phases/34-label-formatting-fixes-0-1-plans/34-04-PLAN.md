<objective>
Make label rectangles self-consistently approximate the configured aspect ratio: the per-line char budget must derive from the text's actual wrapped line count, not from a fixed content-row count. UAT finding (test 1, minor): "the label text rectangle ratio is pretty far from the desired" — a 110-char edge description at the 2-row floor (7 chars/line) wraps to ~16 lines → ≈0.2:1 ratio instead of 1.6:1. User scoped the fix to edge + unit labels.

Closed-form derivation (no iteration — the naive line-count loop oscillates due to ceil):
width = (fixedRows + textLen·pointsPerChar/width) · pointsPerRow · ratio
→ width² − B·width − C = 0, B = fixedRows·pointsPerRow·ratio, C = textLen·pointsPerChar·pointsPerRow·ratio
→ width = (B + √(B² + 4C)) / 2; charsPerLine = width / pointsPerChar.

Supersedes D-03 (fixed 2-row floor) for edge labels; the shape ratio multipliers (cylinder ×2.2, queue ×1.6) are preserved.
</objective>
