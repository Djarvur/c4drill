        - Scan the string rune-by-rune, classifying each rune into exactly three classes: wordChar = unicode.IsLetter(r) || unicode.IsDigit(r); space = unicode.IsSpace(r); separator = EVERYTHING ELSE (punctuation AND symbols — note `>` is Unicode category Sm (symbol), NOT unicode.IsPunct, so the classifier must be "not wordChar and not space", never `unicode.IsPunct`).
