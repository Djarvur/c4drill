<action>
Create a GitHub Actions workflow that validates all TOML examples in the skill/ directory.

**Workflow specification:**
- **Name:** Validate Skill Examples
- **Triggers:** 
  - push to `skill/**` paths
  - pull_request with `skill/**` paths
- **Jobs:**
  - `validate`: runs on ubuntu-latest
  - Steps:
    1. Checkout code
    2. Setup Go 1.26.x
    3. Build c4drill (`go build ./cmd/c4drill`)
    4. Validate all examples (`./c4drill skill/examples/*.toml -f dot > /dev/null` for each file)
    5. Fail if any example fails to parse or validate

**Implementation notes:**
- Use `go version: '1.26'` or `go-version-file: 'go.mod'`
- Use `go build -o c4drill ./cmd/c4drill` to create binary
- Loop through examples or use shell glob
- CI validates during skill development only (per CONTEXT.md decision)
- Do NOT validate user TOML files — only skill/examples/

**Important:** This workflow should only run when skill/ files change, not on every commit.
</action>
