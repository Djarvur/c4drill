<task type="auto">
  <name>Task 1: Add HTML label builder functions to labels.go</name>
  <files>internal/render/labels.go</files>
  <action>
Add four new HTML label builder functions after existing label builders:

1. **buildPersonHTMLLabel** - Person types (TypePerson, TypePersonExternal):
   - Icon (👤) with rowspan=2 on left
   - Name bold on top-right, Description on bottom-right
   - Format:
   ```html
   <<TABLE border="0" cellborder="0" cellspacing="0" cellpadding="2">
     <TR><td rowspan="2" valign="middle" align="center"><font size="+4">👤</font></td>
         <td valign="bottom" align="center"><b>Name</b></td></TR>
     <TR><td valign="top" align="center">Description</td></TR>
   </TABLE>>
   ```

2. **buildDbHTMLLabel** - Database types (TypeDb, TypeDbExternal, TypeContainerDb, TypeComponentDb):
   - Icon (⛁) with rowspan=3
   - Name bold, [technology] italic, Description
   - Format:
   ```html
   <<TABLE border="0" cellborder="0" cellspacing="0" cellpadding="2">
     <TR><td rowspan="3" valign="middle" align="center"><font size="+4">⛁</font></td>
         <td valign="bottom" align="center"><b>DB</b></td></TR>
     <TR><td valign="middle" align="center"><i>[technology]</i></td></TR>
     <TR><td valign="top" align="center">Description</td></TR>
   </TABLE>>
   ```

3. **buildQueueHTMLLabel** - Queue types (TypeQueue, TypeQueueExternal, TypeContainerQueue, TypeComponentQueue):
   - Custom graphics (═╦╩═╦══) with rowspan=4
   - Name bold, [technology] italic, Description
   - Format:
   ```html
   <<TABLE border="0" cellborder="0" cellspacing="0" cellpadding="2">
     <TR><td rowspan="4" valign="middle" align="center">═╦╩═╦══</td>
         <td valign="bottom" align="center"><b>Queue</b></td></TR>
     <TR><td valign="middle" align="center"><i>[technology]</i></td></TR>
     <TR><td valign="top" align="center">Description</td></TR>
   </TABLE>>
   ```

4. **buildGenericHTMLLabel** - System/Container/Component types (no icon):
   - Name bold, [technology] italic, Description
   - Format:
   ```html
   <<TABLE border="0" cellborder="0" cellspacing="0" cellpadding="2">
     <TR><td valign="bottom" align="center"><b>Unit</b></td></TR>
     <TR><td valign="middle" align="center"><i>[technology]</i></td></TR>
     <TR><td valign="top" align="center">Description</td></TR>
   </TABLE>>
   ```

Key rules:
- If technology is empty, omit that row
- If description is empty, omit that row  
- Return empty string if label is nil
- Use valign and align attributes for proper alignment
- All text must be wrapped in <b> for bold, <i> for italic
